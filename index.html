AI-Powered Case Automation & Analytics Platform

A rebuild of the system I designed at BA ABOGADOS, which cut processing time per folio from 4 hours to 20 minutes and scaled into a service for 13 law firms. Because the real system runs on confidential taxpayer data, this demo recreates it end to end on 1,150 synthetic records, from raw multi-firm files to an AI agent and executive dashboards.

  • AI agent with modular skills: automates the full workflow (taxpayer lookup, personalized notices, delivery tracking), with each task built as its own reusable skill
  • Multi-source data pipeline: standardizes 4 inconsistent file formats into one schema in Python, catching duplicates, invalid tax IDs (check-digit validation) and malformed emails before anything is sent
  • Relational data model: a normalized Oracle SQL database (taxpayers → cases) with queries for recovery rate, response trends, case aging and repeat debtors
  • Executive dashboard: Tableau views of debt recovered, response rates by month and an aging breakdown that tells attorneys where to follow up first
Python · pandas · Oracle SQL · Tableau · AI agents. Real-world results from production; demo runs on synthetic data.
